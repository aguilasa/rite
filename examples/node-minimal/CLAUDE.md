# slugkit

Node 20+, standard library only (no dependencies).

- Tests: `npm test` (runs `node --test`).
- `src/index.mjs` is generated by `tools/gen-exports.mjs`; after adding or removing a module in
  `src/`, run `node tools/gen-exports.mjs` and commit both. `node tools/gen-exports.mjs --check`
  fails when the file is out of date.
- `fixtures/golden/` is reference data and is never edited.
